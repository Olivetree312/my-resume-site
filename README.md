## Purpose

This website was built to:

- Present my resume in a more interactive and personal format
- Showcase academic, technical, and creative projects
- Practice modern web development tools and workflows
- Serve as a continuously evolving portfolio rather than a static document

Unlike a traditional résumé PDF, this site is designed to grow alongside my skills and interests.

---

## Tech Stack

Depending on the section, the site uses:

- **HTML / CSS** – layout, styling, and visual design
- **JavaScript** – interactivity and dynamic behavior
- **React / Next.js** – component-based structure and routing
- **Git & GitHub** – version control and collaboration
- **Vercel** – deployment and hosting

Some sections are intentionally simple, while others are used as a sandbox for learning and experimentation.

---

## Site Features

- Resume / experience overview
- Projects and coursework highlights
- Creative or experimental pages
- Interactive elements and mini projects
- Responsive layout for desktop and mobile

Not all sections are “finished” — the site reflects ongoing development.
